# 6-Month SDE Roadmap for JPMorgan Chase

## Overview
This roadmap is designed to prepare you for a Software Development Engineer (SDE) role at JPMorgan Chase. JPMorgan Chase values strong algorithmic skills, system design thinking, financial domain knowledge, and robust software engineering practices.

```
- Detailed explanation if needed
- Reference related issues
```

- Project overview & motivation

## Red Flags to Avoid

❌ **Studying without doing:** Theory without practice won't help
❌ **Solving same type repeatedly:** Move on after understanding pattern
❌ **Ignoring weak areas:** If you get it wrong 2x, focus on it
❌ **No projects:** Projects are critical for interviews
❌ **Memorizing solutions:** Understanding > memorization
❌ **Rushing interviews:** Take time to communicate clearly
